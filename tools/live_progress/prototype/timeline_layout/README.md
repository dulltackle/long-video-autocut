# 阶段时间线布局原型

> PROTOTYPE — 本目录是用于回答「运行列表、直播拆条运行总览与九阶段时间线应如何组成界面」的可丢弃原型，不是生产实现。

三套结构通过同一路由的 `?variant=` 参数切换：

- `A`：纵向叙事——左侧运行列表、连续时间线、当前阶段事实侧栏。
- `B`：阶段控制台——横向九阶段轨道、单阶段详情、语义阶段事实侧栏。
- `C`：审计长表——运行横条与可展开的九阶段高密度表格。

状态场景通过 `?scenario=` 切换：`live`、`failed`、`interrupted`、`corrupt`、`success`。原型底部工具条也可切换方案与场景，并模拟一条新的结构化事件日志事实。

## 运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/?variant=B&scenario=live`。

左右方向键切换方案；输入框、下拉框或可编辑元素聚焦时不会拦截方向键。

## 验证结论

选择 `B` 作为实现规格的视觉层级：九阶段轨道优先于运行级信息；运行选择器采用不挤压轨道的宽浮层（窄屏为全屏抽屉）；桌面右栏呈现供应商请求、重试与退避、缓存等语义事实；预览以固定右侧浮层打开。当前阶段推进时不自动改变操作员选中的阶段，只显示非打断式“查看当前阶段”入口。
