# Triage 标签

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可由 AFK 代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工参与实施 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提到规范角色时，使用对应的 GitHub 标签。
