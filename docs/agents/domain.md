# 领域文档

本仓库采用单上下文领域文档布局。

## 开始工作前

- 阅读根目录 `CONTEXT.md` 中与任务有关的领域语言。
- 阅读 `docs/adr/` 中与当前修改范围有关的架构决策。
- 文件不存在时静默继续，不为完整目录结构而提前创建空文档。

## 词汇规则

议题标题、规格、实现方案、测试名称和代码说明应使用 `CONTEXT.md`
定义的规范术语，避免使用其中明确排除的同义词。

需要引入新领域概念时，先通过领域建模明确含义，再更新
`CONTEXT.md`。

## ADR 冲突

当建议或实现与现有 ADR 冲突时，必须明确指出冲突及重新开启该决策的
理由，不能静默覆盖。
